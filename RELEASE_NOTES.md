Первая стабильная debug-сборка MSM Farmer для Android 8+ (targetSdk 36, Android 16).

Возможности:
- автоматический сбор жёлтых монет на экране;
- обучение по скриншотам: приложение запоминает отпечаток экрана до и после перехода и узнаёт, на каком острове оно находится;
- плавающая панель поверх игр с живым статусом, счётчиками и кнопками паузы/стопа;
- обход островов по обученным маршрутам;
- самообучение жестов и автоподстройка чувствительности;
- обновлённый минималистичный Material 3 интерфейс с главной карточкой-статусом;
- собственная иконка с корректными адаптивными размерами;
- исправлена остановка при сбое захвата экрана.

Установка: скачайте APK и откройте его на телефоне или выполните `adb install -r msm-farmer-debug.apk`. Разрешите спец. возможности, запись экрана и отображение поверх окон.

Подпись: начиная с этой версии все APK подписываются одним постоянным ключом из репозитория (`app/msm-farmer.keystore`), поэтому последующие обновления ставятся поверх без удаления. Если на телефоне стоит одна из предыдущих сборок с ключом GitHub Actions, её нужно удалить один раз.

⚠️ Автоматизация может нарушать правила игры. Используйте на свой риск.
