MSM Farmer 1.4.2 — исправление слишком редких нажатий.

Разбор нового лога показывает: иконки находятся (`иконок=2-3`), но за 205 сканов было всего 4 тапа. Причина — список игнора из 1.3.x: после первого нажатия реальная монета, оставшаяся на месте, помечалась как «статичная деталь» и блокировалась на 5 минут.

- В режиме поиска по иконке игнор отключён — найденные иконки нажимаются каждый проход.
- Игнор сохранён только для режима «цвет» (когда эталон не находит иконки).
- Задержка между повторными нажатиями уменьшена с 4 с до 1.2 с.
- В диагностику добавлено поле «лучший=N%» — совпадение с эталоном.

Версия: 1.4.2 (versionCode 8).

Установка: `adb install -r msm-farmer-debug.apk`.

⚠️ Автоматизация может нарушать правила игры. Используйте на свой риск.
