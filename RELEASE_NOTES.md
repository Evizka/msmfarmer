MSM Farmer 1.4.1 — бот больше не встаёт, если иконка не найдена.

В 1.4.0 поиск по эталону был слишком строгим: если иконка в игре другого размера или слегка отличается, тапов не было вообще.

- Пороги распознавания снижены, диапазон масштабов расширен до 48–300 px.
- Если по эталону ничего не найдено, приложение возвращается к поиску по цвету и продолжает нажимать — жёлтый декор по-прежнему игнорируется после повторных тапов.
- В диагностике появилось поле «режим=иконка/цвет»: по новому логу сразу видно, какой поиск сработал.
- Версия увеличена до 1.4.1 (versionCode 7).

Установка: `adb install -r msm-farmer-debug.apk`.

⚠️ Автоматизация может нарушать правила игры. Используйте на свой риск.
