MSM Farmer 1.4.0 — поиск монет по эталонной иконке.

Вместо срабатывания на любой жёлтый пиксель детектор теперь ищет на экране конкретную иконку монеты из скриншота: жёлтая куча монет с зелёной буквой M на сером фоне.

- В APK встроен эталон иконки; поиск идёт по форме и цвету в нескольких масштабах (64–236 px).
- Сначала находятся похожие по пропорциям участки, затем эталон накладывается точнее; жёлтый декор и интерфейс больше не вызывают тапы.
- В диагностике появились поля «иконок=N» и «шаблон=готов/нет»; экспорт логов показывает их автоматически.
- Исправлен слайдер паузы после монеты: теперь до 6 с (значение по умолчанию 4 с отображается корректно).
- Версия увеличена до 1.4.0 (versionCode 6).

Если вы обновляетесь с версии старше 1.2.0, удалите старую APK один раз.

Установка: `adb install -r msm-farmer-debug.apk`.

⚠️ Автоматизация может нарушать правила игры. Используйте на свой риск.
