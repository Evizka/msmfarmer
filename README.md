# MSM Farmer

Android-приложение для автоматического сбора монет в **My Singing Monsters**. Работает без root: находит жёлтые иконки монет на экране через захват экрана (`MediaProjection`) и нажимает на них через службу доступности. Умеет переключаться между островами: по записанному макросу или по маршрутам, выученным по вашим действиям.

> ⚠️ Автоматизация может нарушать правила игры. Используйте на свой страх и риск. Приложение работает полностью локально: никакие данные никуда не отправляются.

## Возможности

- Сканирование экрана с настраиваемым интервалом (по умолчанию 350 мс).
- Поиск жёлтых иконок по цвету, форме и размеру (без OpenCV и без доступа к файлам игры).
- Тапы по найденным иконкам с защитой от повторного нажатия в ту же точку.
- Настраиваемые зоны игнорирования: верхняя панель и нижняя навигация.
- Режим отладки с подсветкой найденных монет на превью экрана.
- Самообучение переходов: приложение делает компактные «отпечатки» экрана до и после перехода, запоминает жесты и само понимает, на каком острове оно находится.
- Плавающая панель поверх игр: показывает текущее действие, счётчики монет/островов/сканов и кнопки паузы, стопа и скрытия.
- Макрос перехода между островами: последовательность тапов, свайпов и пауз, которую можно записать по скриншоту и проиграть перед сбором следующего острова.
- Автоподстройка чувствительности по текущему кадру.
- Статистика и лог работы.

## Диагностика и логи

Во вкладке «Статистика» показывается состояние детектора: количество жёлтых пикселей, найденных компонент, отсевов по размеру и форме, координаты кандидатов. Раз в 4 секундыэти данные пишутся в лог; каждый принятый системой жест тоже логируется.

Кнопки **«Поделиться»** и **«GitHub issue»** формируют отчёт с версией, моделью телефона, диагностикой, настройками и последними 50 записями лога. GitHub issue открывается в браузере с уже заполненным телом — остаётся только нажать Send.

## Панель поверх приложений

При запуске сбора (при выданном разрешении «поверх других окон») поверх игры появляется небольшая панель:

- текущее действие: «Сканирую», «Нашёл N — собираю», «Вывожу тап/свайп», «Переход на остров N»;
- счётчики: собрано монет, островов, сканов;
- кнопки ⏸ (пауза), ■ (стоп) и ✕ (скрыть панель).

Повторно показать панель можно кнопкой «Панель HUD» на главном экране. Пример: `design/hud-preview.png`.

## Дизайн

Интерфейс сделан в спокойном стиле **«Минимал / Material 3»**: тёплый оф-вайт фон, глубокий зелёный акцент, мягкие сероватые поверхности, тонкие линии и три вкладки — «Главная», «Статистика», «Настройки». Концепт-превью лежат в папке `design/`, тёмная версия — `design/dark-concept.png`.

## Обновление и подпись

Все APK подписываются постоянным ключом `app/msm-farmer.keystore`, который лежит в репозитории. Благодаря этому новая версия ставится поверх предыдущей командой `adb install -r` без удаления. Если у вас установлена одна из более ранних сборок, подписанная временным ключом GitHub Actions, удалите её один раз — после этого обновления будут работать нормально.

## Требования

- Android 8.0 (API 26) или новее.
- Android Studio Meerkat (2024.3.1 Patch 1) или новее с Android SDK 36, JDK 17, AGP 8.9.1+ и Gradle 8.11.1 — для сборки.
- Разрешение на запись экрана и доступность для приложения.

## Сборка

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите устройство или эмулятор и запустите конфигурацию `app`.

Проект собран с `targetSdk = 36`, поэтому корректно работает на Android 16 (включая edge-to-edge и разрешения фоновых служб).

```bash
./gradlew :app:assembleDebug
```

APK будет здесь: `app/build/outputs/apk/debug/app-debug.apk`.

Готовый debug-APK лежит в корне репозитория: [`msm-farmer-debug.apk`](msm-farmer-debug.apk), а также опубликован в [релизе v1.3.0](https://github.com/Evizka/msmfarmer/releases/tag/v1.3.0) вместе с иконкой `app-icon.png`. Он собран через GitHub Actions и подписан отладочным ключом. Установка: `adb install -r msm-farmer-debug.apk` (или просто откройте файл на телефоне и разрешите установку из неизвестных источников).

Иконка приложения: [`design/app-icon.png`](design/app-icon.png) — зелёный квадрат с золотой монетой и ростком. В проекте используются корректные адаптивные иконки: фон задаётся цветом, а передний слой (`drawable-nodpi/ic_launcher_foreground.png`) вписан в безопасную зону launcher-маски.

## Как пользоваться

1. Откройте приложение и нажмите **«Открыть настройки»** в карточке «Доступность». Включите службу **MSM Farmer**.
2. Вернитесь в приложение, нажмите **«Разрешить»** в карточке «Запись экрана» и подтвердите системный диалог.
3. Нажмите **«Запустить сбор»**. Сверните приложение и откройте MSM — монеты будут собираться автоматически.
4. Для остановки разверните приложение и нажмите **«Остановить сбор»** или потяните шторку и нажмите на уведомление.

### Самообучение

Приложение может само осваивать переходы между островами по вашему примеру:

1. Откройте вкладку **«Настройки»** → раздел **«Самообучение»** → **«Обучать»**. При первом запросе разрешите приложению рисовать поверх других окон.
2. Сверните приложение и обычными нажатиями/свайпами сделайте переход к другому острову. Прозрачный слой запомнит жесты и сразу передаст их в игру.
3. На новом острове нажмите плавающую кнопку **«✓ Остров»** (или такую же кнопку в приложении) — маршрут сохранится.
4. Повторите для нескольких островов: во время автоперехода приложение будет циклически выбирать освоенные маршруты. Для полного цикла обучите переход с каждого острова на следующий, включая возврат к первому. При желании можно вернуться к ручному макросу переключателем «Использовать обученные маршруты».

Также есть кнопка **«Обучить по текущему кадру»** в разделе «Распознавание» вкладки «Настройки»: она подбирает чувствительность распознавания под текущую картинку игры (нужно, чтобы монеты были видны на экране). Переключатель **«Подстраивать после перехода»** включает такую подстройку автоматически после каждого перехода на новый остров.

> Обучение жестами — экспериментальная функция. На некоторых оболочках система может блокировать поверхностное окно или собственные жесты доступности; в таком случае используйте ручной макрос по скриншоту.

### Автопереход по островам

1. Пока сбор запущен, откройте вкладку **«Настройки»** → раздел «Свой макрос» — там появится последний кадр экрана.
2. Выберите режим «Тап» или «Свайп» и нажмите/проведите по превью, чтобы добавить шаги перехода (например: открыть карту → выбрать остров → закрыть меню).
3. Добавьте паузы кнопкой **«+ Ждать 1.5 с»**, если игра загружается медленно.
4. Включите **«Переключать острова при простое»**, укажите количество островов и задержку перед переходом.
5. Кнопка **«Тест»** проигрывает макрос сразу, не дожидаясь простоя.

## Настройки

| Настройка | Что делает |
|---|---|
| Интервал сканирования | Как часто приложение проверяет экран. Меньше = быстрее, но выше нагрузка. |
| Чувствительность к жёлтому | Чем выше, тем больше жёлтых оттенков считается монетами. |
| Задержка повторного тапа | Защита от многократных нажатий в одну точку. |
| Максимум тапов за кадр | Ограничение ACTION_PER_FRAME. |
| Показывать найденные монеты | Подсветка кандидатов на превью (для настройки чувствительности). |
| Количество островов | Сколько островов пройти до остановки (или до нового цикла). |

## Ограничения и диагностика

- Распознавание основано на цвете: яркие жёлтые элементы интерфейса тоже могут попасться. Увеличьте порог чувствительности или уменьшите зоны сканирования.
- Если монеты не находятся: включите отладку и посмотрите, подсвечиваются ли иконки. Если подсветки нет — увеличьте чувствительность. Если подсвечивается слишком много лишнего — уменьшите.
- Если тапы не проходят: проверьте, включена ли служба доступности, и не заблокирован ли экран блокировкой/другим окном.
- На Android 13+ приложение запрашивает уведомления. Без них система может остановить фоновую службу.
- Служба доступности привязана к жестам, а не к конкретному пакету игры — это позволяет работать с разными версиями MSM.
- iOS не поддерживается: там нет разрешённых способов перехвата экрана и жестов для таких задач.
